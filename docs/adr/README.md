Michael Nygard's [format](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions).

No decisions have been recorded yet. The first ones come with phase 1 (the initial model and the structure of the
system prompt); the open questions are listed in section 7 of the [brief](../brief.md).
